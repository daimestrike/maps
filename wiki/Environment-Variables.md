# Переменные окружения

Локально читаются из `.env` (шаблон — `.env.example`). В Docker передаются в контейнер через `compose.yaml` / `compose.prod.yaml`, которые сами читают `.env` рядом с собой (шаблон для сервера — `.env.production.example`). `.env` в репозиторий не попадает.

## Приложение

| Переменная | Обязательна | По умолчанию | Назначение |
|---|---|---|---|
| `DATABASE_URL` | да | — | Строка подключения PostgreSQL для Prisma. В Compose собирается автоматически из `POSTGRES_*`. |
| `APP_URL` | да | `http://localhost:3000` | Внешний адрес сервиса. Используется как эталон для проверки заголовка `Origin` во всех небезопасных запросах — при несовпадении API возвращает 403. При смене порта или домена обновляйте обязательно. |
| `COOKIE_SECURE` | нет | `false` | `true` — cookie сессии помечается `Secure` и ходит только по HTTPS. По HTTP с `true` вход не сработает. |
| `ALLOW_REGISTRATION` | нет | открыта | Ровно строка `false` закрывает самостоятельную регистрацию: `POST /api/auth/register` отвечает 403, а ссылка на форму регистрации скрывается. Любое другое значение (и отсутствие переменной) оставляет регистрацию открытой. |
| `SEED_PASSWORD` | для seed | — | Пароль, который получат три предустановленных пользователя. Требования: 12–72 байта, иначе seed падает с ошибкой. |

## База данных и порты (только для Compose)

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `POSTGRES_USER` | `x5` | Пользователь PostgreSQL в контейнере. |
| `POSTGRES_PASSWORD` | — (обязательна) | Пароль PostgreSQL. `compose.yaml` без неё не стартует. |
| `POSTGRES_DB` | `x5_map` | Имя базы. |
| `APP_PORT` | `3000` | Порт хоста, на который публикуется приложение. |

## Сборка и импорт

| Переменная | Когда действует | Назначение |
|---|---|---|
| `NEXT_PUBLIC_TILE_URL` | **на сборке** (`npm run build` / `docker build`) | Шаблон URL тайлов, например `https://tiles.internal/{z}/{x}/{y}.png`. Значение `off` полностью отключает слой тайлов — карта рисует только контуры регионов из `public/russia-regions.geojson`. По умолчанию используются публичные тайлы OpenStreetMap. `Dockerfile` жёстко задаёт `off`, поэтому **в Docker-образе тайлов нет** — это сделано ради работы без интернета. Чтобы вернуть тайлы в образ, пересоберите его со своим значением. |
| `FORCE_STORE_IMPORT` | при запуске seed | `true` — перезалить каталог из CSV, даже если в базе уже достаточно магазинов. Без него seed пропускает импорт, если магазинов в базе не меньше, чем строк в CSV. |

Переменные с префиксом `NEXT_PUBLIC_` попадают в клиентский бандл на этапе сборки. Задавать их в рантайме бессмысленно — значение уже вкомпилировано.

## Задаются самим образом

`Dockerfile` фиксирует `NODE_ENV=production`, `NEXT_TELEMETRY_DISABLED=1`, `HOSTNAME=0.0.0.0`, `PORT=3000`. Менять их не нужно; порт снаружи регулируется через `APP_PORT`.
