# X5 · Карта магазинов

Внутренний веб-сервис: вся торговая сеть на одной карте OpenStreetMap, с карточкой каждого магазина и обсуждением в комментариях. Прототип (MVP), без официальных бренд-материалов X5 и без интеграций с корпоративными системами.

## Что умеет

- Карта всей сети с группировкой маркеров (кластеризация), контуры регионов России работают без интернета.
- Поиск по коду, названию, адресу и городу — без учёта регистра.
- Карточка магазина: адрес, регион, время работы, статус и справочные поля (территория, макрорегион, дивизион, кластер, ЦФО, МВЗ, завод SAP, формат, юрлицо, метро).
- Редактирование карточки и добавление новых магазинов прямо из интерфейса.
- Определение координат по адресу без интернета — по встроенному каталогу (индекс → город → регион).
- Комментарии с автором и временем, постранично по 50, хранятся в PostgreSQL.
- Регистрация и вход по email/паролю, сессии на 7 дней.

## Ключевые цифры

| | |
|---|---|
| Магазинов в каталоге | 25 680 |
| Стек | Next.js 16 (App Router), React 19, TypeScript 5.9, Prisma 6, PostgreSQL 17 |
| Карта | Leaflet 1.9 + markercluster, тайлы OpenStreetMap (отключаемы) |
| Процессов | один: Next.js обслуживает и интерфейс, и API |
| Работа без интернета | да, в офлайн-сборке |
